# TontOS Launcher APK

The Android launcher component for TontOS. Designed for low distraction, monospace typography, pure AMOLED black backgrounds, and system-level privacy controls.

- Maintainer: FalseThinks <paproken@protonmail.com>
- Comprehensive Documentation: See [`docs/JAVA_LAUNCHER.md`](../docs/JAVA_LAUNCHER.md)

## Quick Build

```sh
./scripts/build_launcher_apk.sh
```

Artifact: `launcher_apk/tontos-launcher.apk`
AOSP Privileged Integration: `vendor/tontos/apps/TontOSLauncher/Android.bp`
